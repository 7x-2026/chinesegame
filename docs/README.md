# 开发初始资料

这份目录将产品讨论和已有产物整理为继续开发可用的起点。整体设计建议、历史研究与当前代码实现分别标明，避免把规划当作已完成能力。

## 建议阅读顺序

1. 阅读[产品框架](product/product-framework.md)，了解社区、年龄阶段与故事入口。
2. 阅读[课程与事件设计](product/learning-and-events.md)，确定学习目标如何变成事件。
3. 阅读[NPC 与记忆](product/npc-and-memory.md)，了解人物关系和状态边界。
4. 打开[地图与室内布局](maps/README.md)，核对空间、动线与场景范围。
5. 体验[榕树里活动室](../demos/rongshuli-room/README.md)，区分当前行为与后续规划。
6. 参考[技术路线](development/technical-plan.md)和[下一阶段工作](development/roadmap.md)继续实施。

## 资料版本关系

竞品研究是2026年10月15日的桌面研究，其中提出过聚焦13—18岁等早期方案。后续社区设计讨论将长期范围扩大为幼儿园至18岁，并建议先选择较窄年龄段验证。当前产品框架以本目录中的产品文档为准；完整报告保留形成时的设计建议和论证。

首轮7—9岁初学者、12—16名常驻人物、6—8名重点人物等数量均为建议范围。现有 Demo 只有一个房间、四名人物和一只猫，没有据此宣称学习效果、课程覆盖或市场结果。

## 保存原则

保留最终报告、来源、可编辑地图片段、可运行 Demo 和用于说明的预览。旧版渲染图片、字体缓存、临时抓取网页、测试中间文件和外部托管仓库身份不作为项目资料提交。
