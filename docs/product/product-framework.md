# 产品框架

## 定位

面向外国儿童与青少年的社区生活冒险游戏，以电脑网页端为主要入口。玩家通过交友、购物、合作与解决生活问题使用中文，逐渐熟悉地点和人物，留下能够影响后续事件的经历。

长期覆盖幼儿园至18岁。年龄决定题材、责任与关系，中文水平决定词句难度和提示，已发生的事情决定故事进度。这三条记录分别管理。

## 年龄阶段

| 建议阶段 | 生活重心 | 事件方向 | 语言参与 |
| --- | --- | --- | --- |
| 3—6岁 | 身边的人和物 | 找玩具、选点心、轮流游戏、认识邻居 | 听懂短请求，表达需要、喜好和情绪 |
| 7—9岁 | 开始独立 | 购物、失物、邀请朋友、社区游戏 | 提问、描述、理解顺序与简短交流 |
| 10—12岁 | 参与集体 | 兴趣小组、生日、义卖、调查小问题 | 计划、分工、比较与说明理由 |
| 13—15岁 | 兴趣与自我 | 社团、误会、社区创作、公共空间讨论 | 表达观点、理解语气、解释与协商 |
| 16—18岁 | 自主与责任 | 志愿服务、筹办活动、独立生活与未来选择 | 获取信息、提出方案、复盘与说服 |

年龄边界用于内容规划，需要通过儿童试玩和教学评审调整。青少年初学者应能体验适龄故事，使用较简单语言，不必回到幼儿题材。

## 故事入口与成长

玩家可以直接进入当前阶段：幼儿从新家和邻居开始，青少年从转学、兴趣和新朋友圈开始。每个入口独立交代背景，不要求补完童年。

连续游玩的玩家可在阶段完成后选择成长，保留重要关系、共同经历和纪念品。年龄推进采用章节切换，不按现实生日强制升级。核心伙伴可随玩家成长，更新兴趣和责任；新阶段按需要引入人物。

## 社区与故事结构

社区包含家、学校、商店、公园、餐饮场所、活动中心等可复用地点。中心广场连接生活环线，公交站预留外出故事入口。整体布局见[社区地图](../maps/README.md)。

- 阶段主线提供持续目标与结局。
- 人物故事发展关系，逐步揭示人物背景。
- 生活事件提供自由选择、复习机会和持续更新。

主要循环为：探索 → 遇到事情 → 理解线索 → 交流或操作 → 看到结果 → 开启后续。

## 美术与空间

采用温暖、有生活细节、适合较宽年龄范围的绘本卡通方向。整体地图表达地点和动线；可玩房间通过人物动作、物品和正在发生的事情吸引探索。平面分区图属于制作规划，不代表最终游戏画面。

室内按“建筑 → 房间 → 互动物品”组织，先打磨少量完整房间。同一房间可通过陈设、人物、时间和事件变化服务不同阶段。当前选定活动室作为第一个互动样例。
