# 课程与生活事件设计

## 能力地图

课程覆盖针对明确的年龄段、中文起点和目标水平计算。先形成目标清单，再决定哪些事件承担教学、练习和表现观察。目标尽量写成“玩家能完成什么”。

主要范围包括语音与文字基础、理解与回应、获取信息、表达与描述、叙述与说明、合作与协商、阅读与书面表达，以及文化和语用。课程可参考《国际中文教育中文水平等级标准》，儿童适配需要专门评审。

一个目标可以由多个事件承担，每个事件集中少量核心目标；自由聊天作为补充，不承担唯一的课程保障。语音、识字或书写较难自然融入的部分，可安排与故事相关的短专项活动。

## 事件格式

新增事件时至少说明：

| 要素 | 需要回答的问题 |
| --- | --- |
| 适用范围 | 哪个年龄阶段、中文水平和前置能力？ |
| 触发条件 | 哪个地点、时间、人物关系或已完成事实？ |
| 玩家动机 | 玩家为什么想参与，有什么值得期待的结果？ |
| 行动过程 | 要交流、探索、找物、创作还是协商？ |
| 学习目标 | 本次需要理解和使用哪些能力？ |
| 提示与证据 | 如何逐步帮助，怎样观察独立完成？ |
| 结果 | 世界、人物关系、物品或后续事件如何变化？ |
| 结束与恢复 | 何时结束，如何保存、重试或返回？ |

## 内容丰富与节奏

一次事件突出一个主要目标，尽早交还操作权，结束时提供可见结果。通过信息差、共同创作、资源取舍、临时变化和人物分歧改变问题结构。对白承担推进、信息或关系作用；闲话与幽默应与人物和当前情境相关。

减少重复跑动与连续委托。支持快速移动、必要回顾、语音重听和清楚的当前目标。调度时综合故事进度、兴趣、能力、待复习目标和最近的事件类型。

## 复习与证据

建议分别记录接触、提示下完成、独立完成，以及间隔后在新情境中完成。听、说、读、写分别保留证据，点选正确不能直接等同于会说或会写。

例如“询问时间”先用于邀请朋友，再用于询问营业时间，之后用于处理活动改期。不同情境使玩家需要重新理解和表达。

同时查看两类覆盖：课程目标中有合格事件支持的比例，以及玩家已有独立表现证据的比例。两者不能互换，不能用剧情数量推断掌握程度。

## 当前 Demo 对应

榕树里活动室围绕招牌制作，提供问候、帮忙、颜色、材料、礼貌请求与欢迎等交流机会。词语本包含“帮忙、招牌、丝带、蓝色、颜料、欢迎”。它还没有完整能力评估、间隔复习调度和儿童口语测评。

后续应先为本任务补充能力编号、提示层级和可观察证据，再增加能使用相同能力的新事件。
