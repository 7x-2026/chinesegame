# 下一阶段工作

## 当前起点

已有产品与方法论建议、社区和室内分区、活动室美术方向，以及一段能从开始玩到结束的网页任务。当前节点适合开展小范围体验与课程样章验证。

## 优先事项

| 优先级 | 事项 | 验收关注点 |
| --- | --- | --- |
| P0 | 确定首个年龄段与中文起点 | 题材、界面和语言目标服务同一批用户 |
| P0 | 观察目标儿童试玩 | 能否理解目的、愿否探索、在哪里卡住或退出 |
| P0 | 给招牌事件配置能力目标 | 分清接触、提示与独立表现，保留具体证据 |
| P0 | 改进行走、遮挡和互动反馈 | 避免穿过家具，明确操作结果与当前目标 |
| P1 | 将对话与事件数据从页面逻辑中分离 | 能增加事件而不重写整个房间 |
| P1 | 为人物增加动画和不同角度素材 | 行为与场景一致，减少静态背景人物的限制 |
| P1 | 增加一个复用能力的新事件 | 换人物、目的或限制后仍需理解和表达 |
| P1 | 试验单个受控 AI NPC | 身份、语言难度与事实稳定，失败时能继续玩 |
| P2 | 多场景、跨设备与阶段成长 | 先有可复用事件和稳定存档，再扩大范围 |

## 持续检查

- 覆盖：课程清单中哪些目标已有合格事件，哪些仍缺机会。
- 学习：任务成功是否真正依赖目标能力，能否在新情境中独立完成。
- 体验：是否愿意再次找人物、是否频繁跳过或求助。
- 技术：存档恢复、浏览器表现、语音可用性、响应与失败率。
- 成本：内容制作耗时，以及接入服务后的单次体验开销。

本清单是开发顺序建议，不是已承诺工期或已验证效果。
