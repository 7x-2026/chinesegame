# 榕树里活动室 Demo

一段可完成的单房间社区故事：认识小雨，找蓝丝带、借颜料，选择招牌设计，并在人物回应和社区回忆中看到结果。

[在线体验](https://rongshuli-activity-room.ningyuanyu8.chatgpt.site) · [返回项目总览](../../README.md)

![人物对话预览](../../docs/images/demo-dialogue.png)

## 本地运行

在本目录运行 `npm run dev`，打开 http://127.0.0.1:8787 。项目无需安装依赖。正式站点的静态目录为 `dist`。

## 已实现

- 点击地面沿过道行走，WASD/方向键移动，E 与附近对象互动。
- 四名人物、小猫和照片墙的交互，包含任务前后不同回应。
- 中文对话、可选拼音与英文提示、浏览器朗读。
- 蓝丝带和颜料收集，背包与词语本。
- 三种颜色、三种图案、三种标题的招牌制作，场景展示与共同回忆。
- 当前浏览器的自动存档、继续与重新开始。
- 窄屏提供人物快捷入口，电脑网页为主要体验平台。

## 实现边界

人物采用预设分支和本地关键词识别，没有连接实时语言模型。记忆为此任务的规则状态，不会上传聊天、录音或儿童个人资料。声音依赖设备与浏览器提供的语音能力。房间为插画背景加移动角色与互动层；目前人物为背景中的静态绘制。

## 检查

`npm test` 检查任务前提、材料与制作条件、存档恢复、设计值校验及重复完成。

浏览器检查覆盖任务完整流程、语言提示、恢复、回忆、重玩和窄屏布局。先在仓库根目录执行 `npm ci` 和 `npx playwright install chromium`，启动本地服务后，在另一个终端从仓库根目录执行 `npm run test:e2e`。检查产物输出到本 Demo 的 `test-results/`，不会提交到仓库。

素材来源及提示词见 `ASSET_NOTES.md`。
